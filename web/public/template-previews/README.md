Generated by `npm run previews:templates`.

- Template OS previews are rasterized from the actual vector-PDF renderer.
- Resume Studio legacy/V3/V4 previews use the actual Resume Renderer block markup + CSS.
- Legacy Editor previews use its actual self-contained HTML renderer.
